## Real consuming application

The public candidate was installed into an isolated checkout of Clevixbase at
commit `cd77b7af`. The module graph reported:

```text
github.com/eadwinCode/better-auth-go v1.0.0-rc.1
```

There was no `replace` directive. The consumer test used Clevixbase's existing
`modernc.org/sqlite` driver and mounted `Server.Handler()` beneath
`/api/auth/` in a standard `http.ServeMux`. It then:

1. ran the adapter migration against a real temporary SQLite database;
2. created an email/password user;
3. asserted the host-only `__Host-` session cookie was `Secure`, `HttpOnly`,
   `Path=/`, and `SameSite=Lax`;
4. retrieved the authenticated session;
5. performed sign-out with the required double-submit CSRF token;
6. confirmed the session was revoked.

The mounted flow passed with `go test -race -count=1`. After installing the
consumer's pinned Bun workspace dependencies, the complete Clevixbase
`go test -count=1 ./...` and `go vet ./...` suites passed.

## Promotion decision

No release-blocking security, migration, race, or stable-boundary contract
defect emerged. The candidate is approved for `v1.0.0` promotion.

The v1 compatibility promise remains limited to the root server API, documented
core HTTP/security contract, adapter contract and helpers, MongoDB/PostgreSQL/
SQLite adapters, 35 social-provider presets, and generic OAuth/OIDC consumer.
Every package below `plugin/`, including SSO and SCIM, remains experimental and
outside the v1 stability guarantee.
